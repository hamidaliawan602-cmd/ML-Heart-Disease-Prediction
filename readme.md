HEART DISEASE PREDICTION USING MACHINE LEARNING

Project Description:
This project is a Machine Learning based Heart Disease Prediction application developed using Python and Streamlit.

The application takes different medical parameters as input from the user and predicts whether the person is likely to have heart disease.

Technologies Used:

* Python
* Machine Learning
* Scikit-learn
* Pandas
* NumPy
* Streamlit
* Joblib

Machine Learning Model:

* Logistic Regression

Project Files:

* app.py                         -> Main Streamlit application
* heart.csv                      -> Heart disease dataset
* LogisticRegression_heart.pkl   -> Trained Logistic Regression model
* columns_heart.pkl              -> Saved feature/column information
* scaler_heart.pkl               -> Saved StandardScaler
* requirements.txt               -> Required Python libraries
* README.txt                     -> Project information

Features:

* User-friendly Streamlit interface
* Heart disease prediction
* Input of patient health parameters
* Machine Learning based prediction
* Logistic Regression model
* Data preprocessing and feature scaling

Input Parameters:
The application uses different health-related parameters such as:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise-Induced Angina
* Oldpeak
* ST Slope

How to Run the Project:

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

cd Heart-Disease-Prediction

3. Install the required libraries:

pip install -r requirements.txt

4. Run the Streamlit application:

streamlit run app.py

5. The application will open in your web browser.

Purpose:
The purpose of this project is to demonstrate how Machine Learning can be used to predict the possibility of heart disease based on medical input features.
